# Automatic Translation Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** English is the only text anyone writes; `npm run i18n:sync` translates new/changed text into the active languages, `i18n:check` fails the build when anything is missing or stale, and the birth guide ships translated.

**Architecture:** A registry of flat content sets (key → English) under `scripts/i18n/`. A committed manifest stores, per set/language/key, a hash of the English each translation came from. Sync diffs English vs locale + manifest, translates only missing/stale keys via the Anthropic Messages API, rewrites the locale TS file, updates the manifest. Check runs offline inside Jest.

**Tech Stack:** TypeScript, tsx (scripts), Jest, Anthropic Messages API via `fetch`, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-11-05-i18n-sync-design.md

## Global Constraints

- Active languages = `SUPPORTED_LANGUAGES` codes minus `en` (today `pt-BR`, `es`) — read from `store/useLanguageStore.ts`, never hard-coded in the scripts.
- Hash = FNV-1a 32-bit hex of the exact English string (`lib/i18nHash.ts`), shared by scripts and app — no Node `crypto` in app code.
- `{{param}}` sets must be identical between English and every translation.
- Locale files keep existing key order; new keys appended before the closing `}`; values written with `JSON.stringify` (double quotes).
- `ANTHROPIC_API_KEY` from env or `.env`; never printed. Model `claude-sonnet-5-5`, `max_tokens` 16000, batches of ≤ 60 keys / ≤ 24k chars.
- Translation prompt: warm grandmother voice, feminine second person where the language marks gender, keep `{{params}}`, numbers, units, drug and org names exact, medical facts faithful, no added or dropped content, return JSON object only.
- Diffuse look untouched. No DB writes, no edge-function deploys.

## Review Focus

- English key edited after translation → sync re-translates it; check fails until it does (Task 1 test `stale`).
- Admin-edited (remote) birth topic text differs from bundled English → app shows English/runtime translation, never a translation of older text (Task 4 test `hash mismatch`).
- Translation drops or renames a `{{param}}` → check fails (Task 1 test `params`).
- Locale value containing quotes, `\n`, or unicode round-trips through the writer unchanged (Task 1 test `roundtrip`).
- Key removed from English → removed from locales and manifest by sync (Task 1 test `removed`).

### Task 1: Core — hash, diff, params, locale file writer

**Files:** Create `lib/i18nHash.ts`, `scripts/i18n/core.ts`, `scripts/i18n/__tests__/core.test.ts`

**Interfaces — Produces:**
- `fnv1a(s: string): string`
- `type Manifest = Record<string /*set*/, Record<string /*lang*/, Record<string /*key*/, string /*hash*/>>>`
- `diffSet(english: Record<string,string>, locale: Record<string,string>, done: Record<string,string>): { todo: string[]; removed: string[] }` — todo = keys missing in locale OR `done[key] !== fnv1a(english[key])`; removed = locale keys not in english.
- `paramsOf(s: string): string` (sorted, comma-joined `{{x}}` names); `paramMismatch(en, tr): boolean`
- `readLocaleFile(path): Record<string,string>`; `writeLocaleFile(path, updates: Record<string,string>, removed: string[]): void`

- [ ] Step 1: tests — `fnv1a('abc')` stable 8-hex; diff returns missing + stale + removed; `paramMismatch('Hi {{name}}','Olá {{nome}}') === true`; writer round-trip on a temp file containing `"a \"q\" \n ç"` keeps bytes for untouched keys, replaces updated value, appends new key before `}`, deletes removed line.
- [ ] Step 2: run `npx jest scripts/i18n` → FAIL.
- [ ] Step 3: implement. `fnv1a`: `let h = 0x811c9dc5; for each char code: h ^= c; h = Math.imul(h, 0x01000193) >>> 0; return h.toString(16).padStart(8,'0')`. Reader: line regex `^(\s+)([A-Za-z0-9_]+):\s*("(?:[^"\\]|\\.)*"|'(?:[^'\\]|\\.)*'),?\s*$` — double-quoted → `JSON.parse`, single-quoted → convert to JSON then parse. Writer edits lines in place by key, appends `  key: JSON.stringify(v),` before the last line matching `^}`.
- [ ] Step 4: `npx jest scripts/i18n` → PASS. Add `scripts` to jest `roots`/`testMatch` if not collected.
- [ ] Step 5: commit `feat(i18n): sync core — hash, diff, locale writer`.
